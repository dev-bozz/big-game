# Assets and licenses

This project does not redistribute third-party show artwork, logos, music, or screenshots. The studio environment, emblem, spotlight beams, decorative borders, prize ladder, and modal art are drawn with local CSS and inline React markup. They are original interface elements and do not depend on a network connection.

Audio cues are synthesized in-browser with the Web Audio API (`src/utils/audio.ts`); no third-party sound files are used. The app uses the system font stack and includes no downloaded fonts or image/audio files. This avoids unknown licensing and external runtime asset requests. No external assets could be verified or downloaded in this environment.
